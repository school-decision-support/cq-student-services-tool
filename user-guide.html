2. SLR Manager — complete a Principal Intake

  1. From the landing page, select Create Principal Intake.
  2. Work through the intake fields using the regional SLR Principal Intake process. Record the school, relevant contacts, student profile, current concerns, existing supports and proposed regional priorities as applicable.
  3. Review the entered information for accuracy before handover.
  4. Select Save Intake for Handover to download a JSON file. The filename begins CQR Principal Intake_ followed by the school name.
  5. Provide the JSON to the allocated ROCL using an approved departmental channel. You can also export a Word version or print/save as PDF for reference.

Important: The Word and PDF outputs are readable documents. The JSON is the file the ROCL needs to open and continue the case in the application.

3. ROCL — open your allocated case

  1. From the landing page, select Open Case under Regional Office Case Lead.
  2. On the dedicated ROCL screen, select Open Case again.
  3. Locate and select the JSON file supplied by the SLR Manager, or a JSON backup you previously saved.
  4. Confirm the school, student and allocated case details displayed in the workspace.
  5. Start with Phase 1 — Scan and Assess, or navigate to the appropriate phase if continuing existing work.

5. Work through the four inquiry phases

1 · Scan and Assess→2 · Prioritise and Develop/Plan→3 · Act→4 · Monitor and Review

Phase 1 — Scan and Assess

Review referral and intake information, existing adjustments and supports, available evidence, student strengths and barriers. Identify information that needs to be clarified with the school.

Phase 2 — Prioritise and Develop/Plan

Work collaboratively with school contacts to define the shared problem of practice, agree the scope of regional support and develop the Case Plan. Enter goals, success measures, actions, responsible officers and timeframes in the structured planning section.

Phase 3 — Act

Implement agreed actions. Record consultation, coaching, modelling, observations and adjustments. A compact reference to the agreed goals appears at the top of this phase.

Phase 4 — Monitor and Review

Review progress against the original goals and success measures, identify evidence of impact and agree ongoing responsibilities, next steps and closure arrangements as appropriate.

The departmental collaborative inquiry cycle has five elements; this application combines Prioritise and Develop and Plan into one working phase.

6. Case Plan, Case Summary and Phase Notes

Case Plan

The agreed support plan: goals, actions, responsibilities, timeframes and measures of success. Developed in Phase 2.

Case Summary

A readable record of information documented across the case, including inquiry notes and contacts.

Download Phase Notes

Exports the information from the current inquiry phase as a Word document.

Print / PDF

Opens a print-friendly version; choose Save as PDF in your print dialog.

  1. Navigate to the phase you wish to export.
  2. Select Download Phase Notes for Word, or Print / PDF for a printable copy.
  3. Use Preview Case Summary to review the combined case notes and select the relevant export option.
  4. Use the Case Plan / Regional Support Plan download in Phase 2 for the agreed planning document.

Always review exported documents before sharing them; confirm that headings, fields, actions and responsibilities are complete.

7. Record meetings, calls and observations in the Contact Log

  1. In the case workspace, select Contact Log.
  2. Choose the record type: Meeting / consultation minutes, Scan & Assess observation or Phone / email / other contact.
  3. Choose the inquiry phase and, if relevant, associate the entry with an agreed goal.
  4. Enter the date, participants, purpose, key information, decisions, actions, responsible person and follow-up date as applicable.
  5. Select Save entry. Review the recorded entry in the list below.
  6. Use the log filter to find records by type; export the log to Word or PDF when required.

8. Use Quick Contact Records for OneSchool and the Regional Tracker

Quick Contact Records are short, editable statements intended to reduce repeated typing in external recording systems. They do not automatically create official OneSchool or Regional Tracker records.

  1. Select Quick Contact Records at the top of a phase or from the Contact Log.
  2. Choose a relevant statement from the dropdown, including ROCL-initiated or school-initiated contacts.
  3. Enter the ROCL name/title and school contact title(s), as appropriate.
  4. Edit the generated text to reflect what actually happened, including the reason for contact and agreed next steps.
  5. Select Copy statement.
  6. Open OneSchool or the Regional Tracker, paste the statement into the appropriate record and save it there.
Example: “Email received from {school contact title} regarding {matter}. Information reviewed and next steps identified.” Replace placeholders and remove any details that do not apply.

9. Save, back up and reopen your work

Save Case downloads a .json file containing the case information. This is different from downloading a Word/PDF report.

  1. In the workspace, select Save Case.
  2. Find the downloaded JSON in your browser's Downloads location (or the location you chose).
  3. Keep the latest backup in an appropriate approved location, using a clear filename/version convention.
  4. When moving between phases, use the reminder to choose Save Case & Continue, Continue without saving or Stay here.
  5. To resume work later, return to the landing page, choose ROCL → Open Case and select the latest saved JSON.
  6. After further changes, download a new backup.
Do not rely only on browser autosave. Browser data may be cleared or unavailable on another device. The tool does not automatically synchronise case records to GitHub, OneSchool or SharePoint.

10. Install the tool as a desktop app (Microsoft Edge)

Installing the website as an app gives you a dedicated window and a convenient way to launch the tool. You still need to save and reopen JSON backups as required.

  1. Open the published CQR Regional Case Management Tool in Microsoft Edge.
  2. At the top-right of Edge, select the three dots (…) — Settings and more.
  3. Choose Apps, then Install this site as an app. On some Edge versions, you may see Install CQR Regional Case Management Tool directly in the address bar or Apps menu.
  4. Confirm the app name and select Install.
  5. Edge may offer to pin the app to the taskbar, create a desktop shortcut or launch at sign-in. Select the options you want.
  6. Open the app from your desktop shortcut, Start menu or taskbar.

11. Pin the app to the taskbar or create a desktop shortcut

Option A — immediately after installation

  1. When Edge displays the installation options, select Pin to taskbar and/or Create desktop shortcut.
  2. Confirm any Windows prompt requesting permission to pin the app.

Option B — if the app is already installed

  1. In Microsoft Edge, type edge://apps into the address bar and press Enter.
  2. Locate CQR Regional Case Management Tool.
  3. Open its app options or details and choose the available shortcut/pinning option (wording may vary).
  4. Alternatively, launch the installed app, right-click its icon on the Windows taskbar and select Pin to taskbar, if offered.

Option C — website shortcut without installing

In Edge, open the tool, use the browser menu and look for the available shortcut option. If your version of Edge does not offer a direct desktop shortcut, Windows can create a shortcut to the website URL. A shortcut opens the website but may not provide the same standalone app experience.

12. Troubleshooting and useful tips

The page looks outdated after an update

Press Ctrl + Shift + R in Edge to refresh the site. If installed as an app, close and reopen it. Check that GitHub Pages has finished deploying the latest version.

I can't see the bottom of the landing page

Try scrolling within the page, maximising the window or reducing browser zoom using Ctrl + minus (−). If content remains inaccessible, report the screen size and browser version through Feedback & Suggestions.

The JSON won't open

Check that the file ends in .json and was exported from the tool. A Word or PDF document cannot be opened as an editable case. If a file is corrupted, use the most recent valid backup.

A Word or PDF download didn't appear

Check your browser Downloads list, pop-up permissions and departmental download restrictions. For Print / PDF, choose the PDF destination in the print dialog.

How do I suggest an improvement?

Use Feedback & Suggestions from the landing page. Avoid entering student-identifying information in the survey.

Information handling: The tool uses local browser storage and downloadable files, not centrally managed secure storage. Follow departmental information handling and approved recording requirements for any case information.
