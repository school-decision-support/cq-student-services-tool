# CQ Student Services Tool — Branded v5.1

The original v5.1 application has been preserved, with browser/app icon references added to the HTML head.

## Update the existing GitHub Pages site

Upload **all files in this folder** into the root of the existing `cq-student-services-tool` repository, replacing `index.html`. Commit changes on the `main` branch. The existing URL remains unchanged.

The browser may cache old icons. In Edge, remove the previously installed app (if desired), revisit the site, and install it again to see the new icon. Desktop shortcuts may also retain a cached icon.

**Privacy:** GitHub Pages is public. Use dummy or approved de-identified case information only pending departmental security approval.
